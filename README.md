This is a repository for data and code supporting the manuscript "The landscape effect on seedrain in naturally regenerating tropical forests in Mexico" written by Bianka Fábryová, Laura Marteijn, Jorge A. Meave, Miguel Martínez-Ramos, Pascual Jamangapé Romero, Bartolino Reyes Rios, Mathieu Decuyper, Rens Koper, Alba Gimeno, Lourens Poorter, Dainius Masiliūnas and Iris Hordijk.
